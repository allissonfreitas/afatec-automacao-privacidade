Política de Privacidade — AFATEC Automação

Última atualização: agosto de 2026.

Este aplicativo ("AFATEC Automacao") é uma ferramenta de uso interno, utilizada exclusivamente pela AFATEC Tecnologia e negócios parceiros autorizados (ex: Bem Estar Master) para gerenciar programaticamente suas próprias contas de anúncios na Meta (Facebook/Instagram) através da API de Marketing.

Quais dados o app acessa

O app acessa apenas dados de contas de anúncios, páginas e pixels que já pertencem ao negócio que o administra, através de um Usuário do Sistema autorizado no Gerenciador de Negócios da Meta. Não coletamos, processamos ou compartilhamos dados de usuários finais de terceiros.

Para que os dados são usados

Os dados (métricas de campanhas, insights de desempenho, configurações de anúncios) são usados exclusivamente para automatizar a criação, leitura e otimização de campanhas publicitárias do próprio negócio, incluindo geração de relatórios e dashboards internos.

Compartilhamento de dados

Nenhum dado é vendido, compartilhado ou transferido a terceiros. Os dados permanecem sob controle exclusivo do negócio proprietário da conta de anúncios.

Retenção e segurança

Tokens de acesso são armazenados localmente, com permissões de arquivo restritas, e podem ser revogados a qualquer momento pelo administrador do Gerenciador de Negócios da Meta.
